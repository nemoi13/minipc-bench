# MiniPC Bench

Независимая база тестов мини-ПК, ИИ-серверов и NAS. Собираем результаты из обзоров в одном месте. В карточках можно проверить исходные значения и перейти к источникам.

**Сайт:** https://nemoi13.github.io/minipc-bench/ (русская и английская версии)

> Проект на раннем этапе. Часть устройств в базе демонстрационная (в карточках стоит пометка `demo`), они содержат примерные данные, скрыты по умолчанию в каталоге и не влияют на рейтинги.

## Что есть на сайте

- **Каталог** с поиском и фильтрами: класс мощности, нагрев, пороги бенчмарков, объём памяти, производитель, возможность расширить ОЗУ и SSD, наличие OCuLink и USB4.
- **Подбор под задачу.** Для каждого сценария (школьнику, студенту, офису, играм, локальному ИИ, домашнему серверу, замене NAS, Homelab и других) есть своя страница со списком подходящих устройств и объяснением, почему они подходят.
- **Страницы «ИИ-мини-ПК» и «NAS»**: для локальной нейросети дома или в малом офисе и для домашних хранилищ.
- **Страница каждого устройства**: короткий паспис (процессор, память, видеоядро), результаты тестов, оценки по категориям, ссылки на обзоры.
- **Производители**: кто выпускает мини-ПК и какие их модели есть в базе.
- **«Мой рейтинг»**: вы задаёте важность критериев, и сайт пересчитывает рейтинг под вас.
* Сравнение 2–4 устройств с исходными результатами в одной таблице. Выбор сохраняется в браузере, а ссылкой на сравнение можно поделиться.

## Какие тесты мы собираем

| Группа | Тесты |
|---|---|
| Процессор | PassMark (общий и CPU Mark), Cinebench R23, CPU-Z, Geekbench 6, PCMark 10 |
| Графика | 3DMark Steel Nomad Light, Time Spy, PassMark 3D |
| Накопитель | CrystalDiskMark (чтение и запись), 3DMark Storage |
| Память | AIDA64 |
| Локальный ИИ | скорость генерации LLM (токенов в секунду) на одной и той же модели |
| Нагрев | температура процессора в стресс-тесте |

Из характеристик отдельно отмечаем: распаяна ли память или её можно расширить, число слотов SSD, OCuLink, USB4, TDP процессора.

Если какого-то теста у устройства нет, оно не исчезает из базы: пустой параметр просто пропускается при подсчёте рейтинга.

## Как считается рейтинг

Баллы от 0 до 100 показывают положение устройства внутри нашей базы по каждой категории (процессор, графика, ИИ, холод, эффективность, цена за баллы, наличие). Они считаются только по тем данным, что есть, и пересчитываются, когда в базе появляются новые устройства. Ссылки «Купить» на баллы не влияют.

## Как устроен проект

Сайт статический и собирается автоматически из данных:

- `data/devices.json` — устройства и результаты тестов;
- `data/brands.json` — производители;
- `data/criteria.json` — список тестов, сценарии и правила подбора;
- `build.mjs` — генератор страниц, Node.js без внешних зависимостей;
- `static/` — оформление и скрипты сайта.

Локальная сборка: `node build.mjs` (нужен Node 18 или новее), результат появляется в папке `dist/`.
